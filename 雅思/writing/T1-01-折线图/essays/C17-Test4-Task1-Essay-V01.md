### Task Achievement

Overview 对 openings 的判断基本正确：新开店铺数量总体大幅下降，并伴有波动。但原文中的 `the number of new shops the opened` 有明显笔误，应为 `the number of new shops that opened`，或者直接写 `the number of shop openings`。

Closures 不能准确概括为 `declined gradually`。这条线在2011—2014年先小幅下降、再升至高点、随后回落；2015年突然降至约500，2016年又迅速回升，之后保持在约5,000附近。更准确的 Overview 是：closures 总体波动明显，最突出的特征是2015年的骤降和随后反弹。

本图还存在一个值得概括的关系：除2011年和2015年以外，大多数年份 closures 多于 openings。Overview 不一定必须写这一点，但它比“closures gradually declined”更能反映两条线之间的比较。

Detail 选择的主要节点合理：

- Openings：2011年约8,500；2012年约4,000；2014年约6,000；2015—2017年约4,000；2018年约3,000。
- Closures：2011年约6,500；2013年高点约7,200；2015年异常低点约500—700；2016年恢复至约5,100；之后相对稳定。

### Coherence and Cohesion

按 openings 和 closures 各写一段是自然且稳定的分组。这里不需要根据每一个交点来回切换两条线。

`After the year` 不自然，因为读者无法立刻确定所指年份。应写 `After 2014` 或 `In the following year`。

`From that point` 的使用方向正确，但后面最好加逗号：

> From that point, it showed an upward trend, reaching around 6,000 in 2014.

第二个 Detail 段以 `By contrast` 开头没有问题，但紧接着又使用 `However`，而后一句真正强调的是2015年的异常转折。可以保留 `However`，但前一句必须先完整、准确地说明2011—2014年的常规波动。

### Lexical Resource

主要拼写和名词搭配问题：

- `aroud` → `around`
- `new shops the opened` → `new shops that opened`
- `opening shop` → `shop openings` / `new shops opened`
- `closed shop` → `shop closures` / `shops that closed`
- `an exception sharp drop` → `an exceptionally sharp drop` / `with the exception of a sharp drop`
- `After the year` → `After 2014` / `In the following year`

`shop openings` 和 `shop closures` 是本题最稳定的两个核心名词，可以合理重复。为了避免重复而写 `opening shop` 或 `closed shop`，反而改变了含义：

- `shop openings`：开店数量或开业事件；
- `opening shop`：正在开店，或语法不完整；
- `shop closures`：关店数量或关闭事件；
- `closed shops`：已经关闭的店铺。

### Grammatical Range and Accuracy

本篇最集中的问题是 `at` 与 `to`：

- `stood at around 8,500`：处于某个数值，使用 `at`。
- `declined to almost 4,000`：下降到某个数值，使用 `to`。
- `rose to around 6,000`：上升到某个数值，使用 `to`。
- `dropped to approximately 500`：下降到某个数值，使用 `to`。
- `climbed to around 5,000`：上升到某个数值，使用 `to`。

其他主要问题：

- `the number for opening shop` → `the number of shop openings`
- `fell back 2012` 缺少 `to the 2012 level`，完整表达为 `fell back to its 2012 level`。
- `until by 2014` 不能同时使用 `until` 和 `by`，可改为 `until 2014` 或 `by 2014`。
- `it drop` → `it dropped`
- 多个独立变化阶段不能只用逗号串联，应使用句号、分号或合适的连词。
